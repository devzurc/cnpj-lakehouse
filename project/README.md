# Sistema operacional do projeto

Governança permanente do desafio. Contratos em `specifications/` e `decisions/` prevalecem sobre anotações históricas.

- `requirements/`: requisitos de avaliação e rastreabilidade.
- `specifications/`: contratos técnicos canônicos.
- `decisions/`: ADRs aceitas (incluindo ADR-016 sobre a forma do repositório).
- `knowledge/`: fatos verificados, premissas, glossário e fontes.
- `delivery-history.md`: índice das sprints 00–18.
- `checkpoints/`: prontidão local versus ações externas.
- `templates/`: formatos se um item do backlog for reaberto.
- `active-sprint.md` e `backlog.md`: trabalho residual (hoje S12-01 `blocked`).

Não recriar `project/sprints/*/tasks/` para consultar evidência antiga.
