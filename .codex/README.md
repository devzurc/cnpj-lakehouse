# Assistentes locais do lakehouse CNPJ

Os perfis em `agents/` são revisores somente-leitura. A matriz canônica de seleção de skills e revisores, os limites de autoridade e o método de auditoria estão em `project/specifications/ai-governance.md`.

Use `cnpj-lakehouse-sprint-execution` para trabalho rastreado e `cnpj-lakehouse-workflow-audit` para auditoria transversal. O prompt de auditoria de entrega está em `prompts/audit.md`. As regras de ações externas permanecem em `rules/remote-actions.rules`; nenhum perfil ou skill concede autorização para publicar ou usar cloud.
